# 課序 CourseFlow

針對新竹市立數位實驗高中跨班選修情境的調代課網站。以「每週課程時段＋指定週次異動」為核心，同一份資料可切換教室、老師、班級及個人選課視角。

## 啟動

需要 **Node.js 24 以上**（使用內建 `node:sqlite`），無第三方 JavaScript 執行相依套件、不需要 API 金鑰。

```sh
cd /workspace/Course-scheduling-system
npm start
```

預設埠為 `3000`。可使用 `PORT` 改埠，`DB_PATH` 指定資料庫。`npm run dev` 可監看伺服器檔案變更。開發時使用目前 checkout；雲端任務已隔離，不必另建 Git worktree。

```sh
npm test
```

14 項 Node 測試涵蓋：PDF 擷取基準、日期驗證、申請與核准、週次隔離、撤銷、老師／教室／學生衝堂、共同授課代課、雙向互換、核准時再檢查、選課保存、資料庫重開、來源限制與即時通知串流。

## 主要操作

1. **週課表總覽**：切換教室／老師／班級，選擇週次、搜尋課程；點課程查看來源及原定安排。調課後在原時段保留「已調整」指向新時段的標記。
2. **調代課管理**：選擇老師代課、移動時段／教室、或兩堂課互換。共同授課可指定其中一位老師被代課，其他老師保留。
3. **簽核**：待審申請不影響課表；核准時再次驗證老師、教室及已登錄學生的時段，通過後才生效。退回與撤銷皆保留稽核紀錄。
4. **我的課表**：新增個人選課清單，同一課程的每週時段一起選入。後台核准異動後依課程 ID 自動連動。選課清單 ID 存在瀏覽器，實際選課資料存在 SQLite。
5. **通知中心**：核准、撤銷會產生站內通知，個人選課清單可篩出相關通知。Server-Sent Events 即時同步開啟中的頁面，20 秒輪詢備援；編輯表單時暫緩更新避免覆蓋輸入。
6. **報表**：依實際上課日期的月份統計有效代課節數／分鐘及被代課節數，支援 CSV。每節 50 分鐘，不擅自推算鐘點費。
7. **課表資料管理**：保留三份 PDF，逐堂核對班級與必修／選修／校定必修分類，查看操作紀錄。

## PDF 資料及適用範圍

- 學期：2026-08-31 至 2027-01-21（民國 115 學年度第 1 學期）。
- `public/sources/room.pdf`：2026-09-11 教室空間課表，為時段主要來源。
- `public/sources/class.pdf`：2026-09-07 班級課表，供班級交叉比對。
- `public/sources/teacher.pdf`：2026-09-11 老師個人課表，供教師名單及人工核對參考。
- 擷取 **186 個每週固定課程時段、26 位老師、11 間教室**。這是每週時段數，不是學期總授課節數或獨立課程門數。
- 其中 **178 個時段**可自動比對到班級，8 個未匹配。不同日期的 PDF 可能存在差異，所有資料預設待核對，課程分類預設「待核定」，不依名稱自行判定必選修。
- PDF 以底色標記的第五週起線上課程規則尚未轉成資料欄位；仍須人工確認。老師課表未作自動一致性認證。
- 學生實際選課、學校假日／停課、教室容量、教師授課資格與可代課意願不在 PDF 中，未自行捏造。
- 衝堂檢查以擷取時段和已登錄學生選課為準，未登錄學生無法納入檢查。待審申請不占用時段；核准時重檢避免兩筆申請同時通過造成衝突。
- 資料庫 `data/app.sqlite` 及 WAL 檔已忽略版本控制。正式用於學校前請設計備份、復原與個資保護機制。儲存的核對結果不會修改 `data/seed.json` 或原始 PDF。

可從已保存 PDF 重新產生匯入資料（不要在已有正式異動紀錄時更換 ID 或重新匯入）：

```sh
python -m pip install -r requirements-tools.txt
python scripts/import_pdf.py
```

來源 SHA-256 與頁碼存於 `data/seed.json`。匯入程式從已保存的三份原檔讀取，不依賴聊天附件路徑。

## 瀏覽器驗證（選用）

測試使用獨立測試資料庫，**不要指向正式資料庫**。

```sh
PORT=3001 DB_PATH=/tmp/courseflow-e2e.sqlite node server.js
# 另一個終端執行：
python -m pip install -r requirements-tools.txt
python scripts/browser_smoke.py
```

預設使用系統 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 覆寫，`TEST_BASE_URL` 覆寫測試目標。腳本驗證新增、核准、個人課表、重整保存、報表下載、站內通知、撤銷、原時段標記、課程核對及手機版溢出。它會建立測試紀錄，每次請使用新的測試資料庫。

## 正式上線前的整合

這是**可操作的校務示範工作區**，目前沒有真實帳號登入或伺服器端角色授權，任何能連上工作區的人都能使用管理功能；不適合直接開放給全校。通知已實作站內通知及開啟頁面的即時同步，**尚未寄送 LINE、Email，亦非瀏覽器關閉後的裝置推播**。已讀狀態是示範工作區共用，未分帳號。

正式導入應依序補齊：

1. **學校 SSO 與權限**：學生僅能看自己的課表，老師只能申請相關課程，教務處具有簽核權限；核准人身分需記錄。
2. **學生選課匯入與學期校曆**：由校務系統匯入選課、假日、停課及考試週，處理跨班學生及線上課程規則。
3. **外部通知服務**：LINE Messaging API／Email 服務、收件人對照與同意、失敗重試、送達紀錄；憑證僅放安全環境設定，不寫進程式或聊天。
4. **補課與節數對帳**：將取消、停課與補課分開記錄，補課日期與應授節數連動，避免只調時間卻遺漏課程。
5. **代課資格與鐘點規則**：可代課科目、教師不可用時間、節數上限、核定費率與會計報表。
6. **備份與稽核**：資料庫備份、變更前後差異、通知失敗警示、保存期限。現有操作紀錄保留於資料庫，但並非防竄改的正式稽核系統。

目前不需要秘密變數。未部署或推送到 GitHub，也未設定學校外部服務。
